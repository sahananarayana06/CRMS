# Crime Record Management System

A web-based application designed to streamline crime complaint registration and record management. The system enables citizens to submit complaints, police officers to manage cases and generate FIRs, and administrators to manage police stations, officers, and crime categories.

## 🚀 Features

* User Registration & Login
* OTP Email Verification
* Crime Complaint Submission
* Complaint Status Tracking
* Police Complaint Approval/Rejection
* FIR Generation
* Criminal Record Management
* Police Station & Police Management
* Crime Category Management
* Search & Filter
* Responsive User Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* XAMPP

## 👥 Modules

### Admin

* Manage Police Stations
* Manage Police Officers
* Manage Crime Categories
* Monitor System Data

### Police

* View & Manage Complaints
* Accept/Reject Complaints
* Generate FIRs
* Manage Criminal Records

### User

* Register & Login
* Submit Crime Complaints
* Track Complaint Status.
